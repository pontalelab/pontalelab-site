# おさるのたいこ — 引き継ぎメモ

`games/osarunotaiko/index.html` は単一HTMLファイルで完結する幼児向けリズムゲームです。
外部ライブラリ・画像・ビルド手順なし。キャラクターや背景はすべてインラインSVG、
効果音はWeb Audio APIでその場生成しています（音源ファイルなし）。

## 画面構成

1. **ホーム画面**（`#home-screen`）：「やさしい」「リズム」の2モード選択ボタン。
   選択するとホーム画面がフェードアウトしてゲーム開始
2. **ゲーム画面**（`#stage`）
   - 中央：おさる（SVG）。タップごとに左右交互に腕とバチを振って太鼓を叩く
   - 太鼓：打撃タイミングでへこみ・波紋・打撃音・（Android限定）振動
   - 右上：鳥（固定BPMのメトロノーム役、リズムモード中のみ口から音符を出す）
   - 背景：手前/奥の2層の木。判定に応じて下から上がる/下がる
   - 木が上がりきると「パーティ状態」：虹色スクロール背景、キラキラ、鳥の合唱隊、
     踊る小猿が出現。2秒間の猶予後に解除

## ゲームモード（`gameMode`変数で分岐）

- **やさしい**：タップ間隔が250ms以下（=1秒に4回以上のペース）なら「リズムが合っている」
- **リズム**：固定BPM=100（`TARGET_INTERVAL`）からのズレが22%以内なら「合っている」

判定が合うと`treeLevel`（0〜100）が+14、外れると-22。何もしなくても0.4秒ごとに-3ずつ自然減衰。
`treeLevel>=100`で`#stage`に`.party`クラスが付与され、賑やか演出一式が発火。

## Pontalelabサイトへの組み込みで変更した点

- サイト共通のhead要素（アイコン・OGP・analytics.js）を追加
- `#stage`の外側（DOM的に兄弟要素）に、ゲーム一覧へ戻る導線（`#site-back-link`）を追加。
  `#stage`にはタップ全体を太鼓の打撃として拾う`pointerdown`リスナーがあるため、
  戻るリンクを`#stage`の内側に置くとタップがバブリングして誤って太鼓を叩いた扱いに
  なってしまう。それを避けるため意図的に外側の兄弟要素にしている
- **実機確認で発見・修正したバグ**：モード選択ボタン（「やさしい」「リズム」）は
  `#stage`の内側にあるため、ボタンを押した瞬間の`pointerdown`が`#stage`まで
  バブリングし、遊び始める前に「たいこを1回叩いた」扱いになっていた
  （スコアが1から始まる、音や振動が鳴る）。`#stage`のpointerdownハンドラで
  `gameMode === null`の間は無視するよう修正した

## 既知の制約・引き継ぎ時の注意（原作者メモ）

- 太鼓とおさるの位置関係はCSSの`margin-top`（概算値）で調整しているだけで、
  実機での正確なピクセル一致は未検証。バチと太鼓の接触位置がずれる場合は
  `#drum-wrap`の`margin-top`を微調整する
- Vibration APIはiOS非対応（仕様上の制約、コード側の不具合ではない）
- スコアや木のレベルなどの状態はすべてメモリ内変数のみで永続化なし
  （リロードで初期化される）
