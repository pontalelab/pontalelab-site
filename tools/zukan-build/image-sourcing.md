# 画像調達フロー（ゲームに登場しない新種を追加する場合）

第一弾7種は、むしたんの既存イラストを流用したため画像調達は不要でした。ここでは、**今後ゲームに登場しない新しい昆虫を図鑑だけに追加する場合**の画像調達フローを、実務で使える手順としてまとめています。

## 基本方針

1. まずは Wikimedia Commons を第一候補とする（ライセンスが明示されており、後から出典を示しやすいため）
2. 1種につき候補を3枚以上集めてから選ぶ（1枚目をそのまま採用しない）
3. 最終的な採用判断は必ず人が行う（自動採用しない）

## 選定チェックリスト

新しい昆虫を1種追加するたびに、以下を順番に確認します。

1. **種の同定が合っているか**：ファイル名・カテゴリだけで判断せず、説明文や学名を確認する
2. **ピントと画質**：小さな画面（スマホ）で見ても虫の形がはっきり分かるか
3. **虫が十分大きく写っているか**：背景に埋もれていないか
4. **子どもが「かわいい」「かっこいい」と感じそうか**：図鑑的な正確さと同じくらい、見た目の魅力度を重視する
5. **ライセンス**：CC0（表記不要）／CC BY・CC BY-SA（表記が必要）を確認し、表記が必要な場合は撮影者名・ライセンス名・出典URLを必ず控える
6. **画像サイズ**：スマホ表示で十分な解像度があるか（目安：長辺800px以上）

## データへの記録方法

`data/<category>/*.json` の `images` 項目に、そのまま記録します。

```json
"images": [
  {
    "url": "/zukan/assets/mushi/xxxxx.jpg",
    "source": "wikimedia",
    "credit": "撮影者名",
    "license": "CC BY-SA 4.0",
    "sourceUrl": "https://commons.wikimedia.org/wiki/File:xxxxx.jpg"
  }
]
```

`source` が `"own-asset"`（自社イラスト）か `"wikimedia"`（外部調達）かで、詳細ページのクレジット表示を自動的に出し分けます（自社イラストの場合はクレジット非表示、外部調達の場合は撮影者名とライセンス、出典リンクを自動表示）。

## 将来の半自動化について

「画像候補を自動収集→評価→提示」という半自動ワークフローは、上記の手順が人力でも十分実行できることを確認できたため、当面は人力運用で問題ありません。掲載数が増えて手間が無視できなくなった段階で、この手順をそのまま自動化の仕様書として使えます。
