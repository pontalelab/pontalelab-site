# けんけんちず 都道府県データ生成ツール

`games/kenkenchizu/src/SilhouetteQuiz.jsx` 内の `QUESTIONS` 配列に追加する、都道府県シルエットのSVGパスを生成するためのツールです。外部ライブラリへの依存はありません（Python標準ライブラリのみ）。

現在12/47都道府県分のみ実装済みです（北海道・青森県・石川県・福井県・静岡県・京都府・千葉県・愛知県・和歌山県・高知県・鹿児島県・沖縄県）。残り35都道府県は未実装です。

## 新しい都道府県を1つ追加する手順

1. このディレクトリで、追加したい都道府県のJISコードを指定してスクリプトを実行する。

   ```bash
   python geojson_to_svg.py japan_geojson.txt 13 27 40
   # 13=東京都, 27=大阪府, 40=福岡県 のように、複数まとめて指定できる
   ```

2. 出力されるJSオブジェクト（`kana` / `feature` / `choices` はプレースホルダー）を、`games/kenkenchizu/src/SilhouetteQuiz.jsx` の `QUESTIONS` 配列に貼り付ける。

3. プレースホルダーを埋める。

   - `kana`: 都道府県名のひらがな読み
   - `feature`: 「🐾 であえる いきもの」形式で、その県で実際に出会える生き物の紹介文をひらがなで作成（1〜2文、40字前後）。**架空の生き物や不正確な生息地情報を書かないこと**（要事実確認）
   - `choices`: 正解1つ＋実在する近隣/紛らわしい都道府県3つのひらがな読み（**必ず実在する47都道府県のみ**。架空の地域名は禁止）

4. `viewBox="0 0 100 100"` で見づらい場合（離島が多い県など）のみ、個別に調整してよい。基本は触らなくてよい。

5. 追加後は必ず確認する。
   - `choices`・`kana`・`feature` に漢字が混入していないこと（対象年齢が未就学〜小学校低学年のため、画面表示テキストはひらがな・カタカナのみ。`name`は内部データなので漢字のままでよい）
   - `choices` がすべて実在する47都道府県のひらがな読みであること

## ファイル

- `japan_geojson.txt`: 47都道府県ぶんの実際の境界線データ（GeoJSON）。`properties.id` がJIS都道府県コード（1〜47）、`properties.nam_ja` が都道府県名。
- `geojson_to_svg.py`: 上記からSVGパスを生成するスクリプト。
